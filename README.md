# ⚡ Harry Potter Catalog

Um catálogo de filmes da saga **Harry Potter**, desenvolvido com React e Vite.

Este projeto foi criado com o objetivo de praticar os fundamentos do React, explorando a criação de componentes reutilizáveis, passagem de propriedades (props) e organização do código.

Durante o desenvolvimento, também experimentei efeitos visuais e estilizações com CSS, utilizando o ChatGPT como ferramenta de apoio para explorar possibilidades e aprender novos recursos.

## ✨ Funcionalidades

- Exibição dos oito filmes da saga Harry Potter.
- Cards reutilizáveis para apresentar os filmes.
- Passagem de dados entre componentes utilizando props.
- Exibição de imagens e títulos de cada filme.
- Organização do conteúdo em componentes separados.

## 🛠️ Tecnologias utilizadas

## 🚀 Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/Lucianoquintela/harry-potter-catalog.git
```

**2. Entre na pasta do projeto:**

```bash
cd harry-potter-catalog
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento:**

```bash
npm run dev
```

**5.** Acesse no navegador o endereço informado pelo Vite.
